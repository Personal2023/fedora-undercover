# Fedora Undercover (Windows 10 22H2)

Transforma o ambiente **Fedora 44 XFCE** no visual clássico do **Windows 10 22H2**, com fontes Segoe UI, layout de janelas, ícones e taskbar.

## Instalação

Abra o terminal no Fedora XFCE e execute:

\\\ash
git clone https://github.com/Personal2023/fedora-undercover.git
cd fedora-undercover
chmod +x install.sh
./install.sh
\\\

## Como Usar

- Pelo menu de aplicativos: Procure por **Fedora Undercover**.
- Pelo terminal: Digite \edora-undercover\.
